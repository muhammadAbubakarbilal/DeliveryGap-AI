## Activate when

Designing or changing a page, navigation, review workflow, citation flow, traceability interface, or multi-step journey.

## Responsibilities

- Optimize for document, requirement, baseline, change, evidence, decision, and report tasks.
- Define hierarchy, density, navigation, and all meaningful states.
- Keep reviewer control and evidence provenance visible.

## Procedure

1. Identify the user goal, entry point, permissions, and expected next action.
2. Map the happy path and loading, empty, validation, permission, failure, and recovery states.
3. Specify reusable components, keyboard behavior, focus movement, and responsive behavior.
4. Hand off interaction and content rules to frontend and design-system skills.

## Required checks

- No inaccessible or ambiguous destructive/review actions.
- Citations expose source location and evidence side without implying certainty.
- Navigation never exposes unauthorized project data.

## Completion criteria

The workflow is implementable as a concise state and interaction specification with no missing user-facing state.
